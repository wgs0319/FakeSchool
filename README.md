# 🎓 학사 및 성적 통합 관리 시스템 (Console Based)

## 📌 프로젝트 소개
Java와 Oracle DB를 연동하여 학생 정보와 성적 데이터를 체계적으로 관리하는 학사 시스템입니다. 
단순한 데이터 저장에 그치지 않고, 복잡한 성적 산출 알고리즘과 데이터 무결성을 보장하는 관계형 스키마 설계에 집중했습니다.

## 🛠 기술 스택
- **Language:** Java 17
- **Database:** Oracle Database
- **Library:** JDBC (OJDBC8), Lombok
- **Tool:** Eclipse, SQL Developer

## ✨ 주요 기능
1. **학적 관리:** 학생 및 교수 계정 생성, 수정, 탈퇴 처리 (CRUD)
2. **수강 및 성적:** 과목 등록, 수강 신청 및 성적 입력/수정
3. **GPA 자동 산출:** (점수 * 학점) 총합 / 총 이수학점 기반의 4.5 만점 학점 산출 알고리즘 적용
4. **통계 분석:** 과목별 평균, 최고점, 최저점 및 성적 분포(A~F) 통계 제공
5. **예외 처리:** 유효하지 않은 점수 입력 시 커스텀 예외(`CalculateException`) 발생 및 트랜잭션 무결성 유지

## 💻 핵심 구현 포인트
- **DB 스키마 설계:** 학생-과목-수강 테이블 간의 외래키 제약조건을 통한 참조 무결성 확보
- **DAO 패턴:** DB 접근 로직을 분리하여 유지보수성 향상
- **보안:** 사용자 비밀번호 및 개인정보 관리 기능 구현
